# 圆周旅迹深度拆解（头号对标）

> 版本：v1（2026-09-21） | 素材来源：用户保存的产品工作页 HTML（`download/圆周旅迹详情页.html`），内含一段完整的"圆周AI"真实规划对话快照 + 行程详情页 UI 结构
> 案例：用户输入"想去成都、九寨沟、峨眉山、乐山、三星堆、黄龙玩6天，想看熊猫，逛成都"，AI 产出 10.01–10.06 六日环线方案并迭代一轮

## 1. 产品架构观察（从页面结构还原）

- **三栏结构**：左侧"圆周AI"对话栏（可收起）｜ 中间行程详情（画布/列表双视图切换）｜ 右侧推荐/待计划/收藏面板
- **顶部**：行程标题、日期（6天5晚）、可见性（仅自己可见）、新人引导、分享
- **功能入口**：智能解析、路线优化（两个显式按钮，行为待实机验证）
- **工具栏**：便签 / 清单 / 图库（图片空间）——通用工具，与行程数据的关系从页面看是松耦合
- **收藏/待计划面板**：默认收藏夹按 游玩/吃喝/购物/住宿/其他 五类计数，有独立"待计划"tab
- **地图**：© AutoNavi——**与我们同用高德底座**；按天显示段里程（33km/168km/204km/406km）

## 2. 对话规划流还原（含金量最高的部分）

圆周AI 的一段完整会话展示了相当成熟的规划行为链：

1. **澄清先行**：没有直接生成，先做地理可行性交底（"九寨/黄龙与峨眉/乐山方向完全相反，6天硬塞是打卡模式"），然后**只问一个最关键的取舍问题**（"先拟一版全去的，还是做取舍？"）。这与我们 §澄清策略"单轮最多问1-2个、按阻塞度选问题"高度一致。
2. **透明化搜索**：显式展示搜索动作（"正在搜索攻略信息..."）、完整查询词、以及**来源引用块**（小红书、新浪、官网 panda.org.cn、时刻表站等，每轮 10+ 条）。
3. **生成+自检**：产出按日方案后标注"已保存并**检查通过**"——存在某种生成后校验环节（检查内容未知，待实机验证）。
4. **指令级迭代**：用户一句"把峨眉乐山放前面、九寨黄龙放后面"，AI 整体重排并给出重排逻辑（减少折返）；调整精确到**具体班次**（返程定为 C15/C18 次 19:00 发车）并说明**缓冲推理**（"国庆堵车风险高，宁可早到站等车"）。
5. **主动建议 chips**：每轮末尾给出 2-3 个可点击的下一步建议（查班次/查天气/查余票）。
6. **风险提醒**：主动提示抢票时点（"10/6 返程票全线最紧张"）、海拔适应、衔接确认。

## 3. 结构化行程模型（从详情页还原）

- 行程项有**类型标签**：游玩/购物/交通/入住（住宿）
- 项间挂**距离+耗时**（21.8千米 36分钟）；无路线可用时退化为**直线距离**（黄龙"直线距离20.4千米"——印证了 M2：高德跨城只有驾车+测地线）
- 交通项时间化：07:00 成都东站 → 08:15 峨眉山站，1小时15分钟，附价格区间（二等座约130-200元）与换乘说明
- 住宿以"入住XX片区"呈现（报国寺片区/九寨沟沟口），带选址理由——**片区级建议，无具体酒店**，与我们 B4 简化版思路一致
- 每项可"添加图片"，便签/清单/图库为通用附件工具

## 4. 与 Riddle 共识的对照

### 4.1 它也有（此前矩阵低估或未知的）
- **对话式深度迭代**：指令级重排 + 班次级调整 + 缓冲推理，比我们矩阵中"⚠️ 对话追加浅"的评估强得多 → **矩阵已回写修正**
- **澄清先行 + 透明搜索引用**：它的信任策略是"让你看到我在查、查了哪"
- **片区级住宿建议**
- **"待计划/收藏"面板**：候选池概念的雏形（五类收藏夹 + 待计划 tab）→ H3 护城河表述需收紧：池的"形"它已有萌芽，但**没有"任意素材解析入池→评估→转正"的管线**，导入仍停留在链接/地点提取

### 4.2 我们仍有差异的（护城河复核）
- **事实性策略**：它靠 websearch + 来源引用——动态信息靠搜，来源权威性参差（小红书/hao86 时刻表站与官网混杂），本质是把验证成本转嫁给用户点链接；Riddle 是 L0 数据源直取 + Jev 校验 + 查不到就留空（C10）。**"语义闭环核验"叙事（W3）依然成立**
- **checklist 深度**：它的"清单"是通用工具（与便签/图库并列），未见与行程实体关联、分类、相对截止、信息类三要素（M3）；Riddle 的 B6 是从图派生的 readiness 视图，**第二护城河（H4）依然成立**
- **版本/回滚**：页面无任何版本管理痕迹；我们的 event sourcing（C8）+ 传播矩阵（C7）无对应物
- **变更传播**：它的迭代是"AI 重新生成一版"，未见"删一个点只动涟漪范围"的图操作语义

### 4.3 值得借鉴的
- 澄清问题的问法（先交底地理难度，再只问一个取舍）
- 来源引用块（信任建设的低成本手段——我们可在 L2 内容区采用）
- 主动建议 chips（每轮末尾的下一步引导，可挂到我们的意图路由输出上）
- 缓冲推理透明化（"宁可早到站等车"——把权衡说出来）
