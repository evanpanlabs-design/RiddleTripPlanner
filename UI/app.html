设置

LLM 生成模型

负责写方案、改方案的生成模型；判断全部由下方 Jev 引擎做出，LLM 不参与判断。保存后即时生效。测试用 models 列表接口，不产生生成费用。

Jev 判断引擎

意图分类 / 槽位复核 / 半径判定 / 语义校验，全部由 Jev 做出。Jev 不可用（网络断/超时/未配置）时自动退级到 LLM 按同一判断 schema 承接，恢复后自动切回。测试会发一次最小判断请求。

高德地图

Web 服务 key 用于 POI / 驾车路线解析（保存即生效，测试走此 key）；JSAPI key 用于前端地图渲染（保存后刷新页面生效，需在页面上实际渲染验证）。
能力分工：高德 = 底图渲染 + POI 检索 + 同城驾车（固定承担）。
内置预设即选即用（保存后刷新页面生效）；想自己调低饱和/高明度风格，去高德开放平台 → 自定义地图平台调色发布，把样式 ID 填到上面即可。

百度地图

能力分工：百度 = 跨城大交通（火车/飞机/大巴，真实班次+时刻+票价）——配置服务端 AK 即自动启用，未配置时跨城段降级为留空待回填。浏览器端 AK 预留。

系统

一轮对话超过该时长强制中止（agent loop 无自带迭代上限的保险丝；正常一轮含地理解析约 60–90s）。
速率限制：留空走默认（地图 QPS 2.5，与官方并发上限对齐）。LLM RPM 作用于后台判断器的密集调用（Friday 网关默认 5），主对话流不限制。
